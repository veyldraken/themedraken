# Themedrakon

A dark VS Code color theme inspired by my dragon character 🐉

![him](https://media.discordapp.net/attachments/1528511411104256120/1532208698359939214/3.png?ex=6a6c040c&is=6a6ab28c&hm=7de1d569f38b81ce1bfb7390f5d098a00b39b193ea90d782908ac0d01373527c&=&format=webp&quality=lossless&width=873&height=1024)
## Palette

- **Gray** — editor background, the base tone of the dragon's scales
- **Deep navy** — panels, sidebar, and status bar, echoing the underbelly and wings
- **Violet** — keywords, classes, and crystal-accent highlights
- **Gold** — strings and active tabs, drawn from the eyes

## Installation

### From source
1. Clone this repo
2. Open the folder in VS Code
3. Press `F5` to launch an Extension Development Host with the theme active

### From a packaged `.vsix`
1. Download the `.vsix` from [Releases]([https://github/veyldrakon/themedrakon/releases](https://github.com/veyldraken/themedraken/releases))
2. In VS Code, open the Command Palette (`Ctrl+Shift+P`)
3. Run **Extensions: Install from VSIX...** and select the file

## Usage

Once installed, open the Command Palette and run **Preferences: Color Theme**, then select **Themedrakon**.
